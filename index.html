ZenCode is an Android mobile application designed with a focus on user privacy and message security. Standard Encode/Decode operations are performed locally on the user's device.

However, the Zen-Chat feature may require an Internet connection and online service infrastructure.

1. Information Collected and Processed

Depending on the features used, ZenCode may process the following information.

1.1 Profile Information

  • GSM / telephone number
  • Optional name
  • Optional email address
  • Profile photo

1.2 Message Content

  • Messages written by the user
  • Encoded / Decoded messages
  • One optional Encode record saved by the user

Standard Encode/Decode operations are performed locally on the user's device.

1.3 Contacts

If permission is granted, ZenCode may access contact information stored on the device.

  • Name and surname
  • GSM / telephone number
  • Email address, if supported by the device

Contact information is processed locally to support GSM verification and convenient contact selection.

1.4 Camera / Gallery

With the user's permission, camera or gallery access may be used to capture or select a profile photo.

Profile photos may be stored locally on the device for use by the relevant ZenCode features.

1.5 SMS Verification Code

  • For GSM verification, the user manually enters a verification code received from an external SMS service.
  • ZenCode does not send SMS messages.
  • ZenCode does not automatically read incoming SMS messages.
  • The application does not use the READ_SMS or RECEIVE_SMS permissions.
  • The verification code entered by the user is processed locally and is not transmitted by ZenCode to third parties.

1.6 Voice Typing and Speech Recognition

ZenCode provides an optional voice typing feature that allows users to compose messages without using the keyboard. The user starts this feature by tapping the microphone icon.

  • Speech recognition is performed through the Android operating system's speech recognition service (Speech Recognition / RecognizerIntent).
  • Recognized speech is converted into text and inserted into the message input field. The user can review and edit the text and decides whether to send the message.
  • ZenCode does not upload voice recordings in MP3, AAC, or any other audio file format to its own servers as part of this feature.
  • The ZenCode application does not transmit audio recordings or Base64-encoded audio data to the Supabase database.

Speech recognition may be provided by the Android speech recognition service available on the device and the service provider configured on that device. Depending on the provider's implementation, audio data may be processed locally or transmitted to the provider's online infrastructure for speech recognition. Such processing is subject to the relevant service provider's privacy policy and data-processing terms.

2. Zen-Chat

Zen-Chat provides real-time messaging using an Internet connection.

Zen-Chat allows users to communicate with each other through ZenCode over the Internet.

Before transmission, the message created by the user is Encoded using ZenCode's Encode mechanism.

The Encoded message may then be transmitted through the online service infrastructure in order to deliver it to the intended recipient.

2.1 Use of Supabase

ZenCode may use Supabase to transmit and temporarily store Zen-Chat messages for delivery to the intended recipient.

The following information may be temporarily processed through the Supabase infrastructure:

  • Encoded message text
  • Message sending timestamp

Content created using voice typing is converted into text and inserted into the message input field after speech recognition. When the user sends the message, only its textual content is transmitted through Zen-Chat, just like any other text message. Audio recordings and Base64-encoded audio data are not sent to Supabase.

Message Retention: Encoded Zen-Chat messages stored within the service infrastructure are automatically deleted after a maximum period of 3 hours from the time they are sent.

2.2 Firebase / Firebase Cloud Messaging (FCM)

ZenCode may use Firebase Cloud Messaging (FCM) to notify the recipient that a new Zen-Chat message has arrived.

The purpose of Firebase/FCM is to display a push notification informing the recipient that a new Zen-Chat message is available.

The message itself, including its Encoded content, is not included in the push notification. The notification is intended only to inform the user that a new message is available.

Technical notification information and device-related notification identifiers may be processed by Firebase as necessary to provide the notification service.

2.3 Zen-Chat Message Security

Zen-Chat messages are Encoded before being transmitted to the online service infrastructure.

The server-side system receives the Encoded form of the message. The required Decode operation is performed on the recipient's device in order to display the readable message content.

ZenCode does not intend to maintain a permanent archive of Zen-Chat messages.
